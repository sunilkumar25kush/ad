## 🚀 How to Experience the Commercial

### 1. View in Any Browser
Open via a local server:
```bash
python -m http.server 5178
```
- **16:9 Master Edition**: `http://127.0.0.1:5178/index.html`
- **9:16 Vertical Edition**: `http://127.0.0.1:5178/vertical.html`

### 2. Audio Control
Click the **"Enable Sound"** button at the top-left to activate the procedural audio engine.

### 3. Developer / Scrubbing Mode
Add `?debug=1` to the URL:
```
http://127.0.0.1:5178/index.html?debug=1
```
- Scrub to any millisecond of the 40-second timeline.
- Spacebar to pause/play, `R` to restart.
- Click **"Record MP4"** for 1-click in-browser video export.
